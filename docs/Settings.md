# Settings panel

Open it with the settings button on the roll widget. Changes apply at once and are saved to `settings.cfg`.

| Setting | What it does |
|---|---|
| Master switch | Turns every roll on or off. |
| Categories | One switch per category. |
| Cancel | Per category: whether a failure may cancel the action. |
| Fail chance | Chance (percent) that an ordinary fail cancels and penalizes. Default 20. |
| Bonus chance | Chance (percent) that a pass earns a bonus. Default 20. |
| Dynamic DC | Lets the main emotion and stacked modifiers move the difficulty (5 to 30). |
| Lethal hazards | Allows the real deadly versions. Default **off**. |
| Language | Switches the settings and the roll widget at once. The failure messages follow a few seconds later. |

The title shows the mod version. If the panel looks stuck on first run, give it a minute: the mod is writing its config files.
